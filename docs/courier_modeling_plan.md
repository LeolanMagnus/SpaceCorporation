# План моделирования: Космический курьер (cabotage courier)

## Концепция
Утилитарный буксировщик-контейнеровоз для каботажных перевозок внутри большой
космической станции. Маршевых двигателей НЕТ. Дизайн «как у складского
вилочного погрузчика»: брутальный, прямоугольный, с силовым каркасом,
нависающими буферами и видимой функциональностью. Всё читается с 3 метров.

## Габариты (жёсткое ТЗ)
- Грузовой отсек/посадочное место: стандартный контейнер **2 × 2 × 4 м** (Ш × В × Д).
- Общая длина с кабиной и рейлингом: ~6.5–7 м.
- Ширина по рейлингу/буферам: ~2.4–2.6 м.
- Единственное жёсткое ограничение: контейнер 2×2×4 встаёт в грузовую рамку чистого габарита 2.05×2.05×4.05.

## Структура объекта (high level)
1. **Грузовая рама (cargo frame)** — силовая прямоугольная рама 4.1 м длиной,
   из квадратного профиля ~0.15 м. Внутри — «вилы» направляющие снизу (отсылка
   к вилочному погрузчику): два продольных швеллера, на которые садится контейнер.
2. **Кабина (monocoque pod)** — одноместная герметичная капсула WITHOUT шлюза:
   гладкий бочкообразный корпус ~1.3 м Ø, плоское трапециевидное панорамное
   стекло (многосегментное, «плоские панели как у техники», не блистер-пузырь),
  Mounted сзади-сверху рамы на короткой шейке. Никаких дверей наружу — вход только
   через стекло-люк/внутренний, снаружи гладкая обшивка с заклёпочными швами.
3. **Рейлинг в два уровня** — перильные дуги вдоль всей грузовой площадки:
   нижний ярус ~0.5 м, верхний ~1.6 м от палубы рамы, с вертикальными стойками
   каждые ~1 м и натянутыми тросами/прутками. Спереди — откидные упоры-стопоры.
4. **Маневровые движки (RCS)** — NO маршевых. 8–12 маленьких сопел:
   - 4 на кормовой плите (по паре: тангаж/рыскание),
   - 2 на носу (торможение),
   - 2 наверху + 2 внизу (вертикаль),
   - 2 боковых пары (сдвиг).
   Сопла — короткие конусы Ø0.12–0.2 м в гнёздах на поворотных кронштейнах.
5. **Защитные скобы над соплами (cage brackets)** — обязательная деталь ТЗ:
   каждая сопловая группа обхвачена П-образной/подковообразной стальной скобой
   из квадратного прутка ~0.05 м, приваренной к плите. Скобы выходят за срез
   сопла на 3–5 см — при контакте со станцией удар приходится на скобу, не на сопло.
6. **Бамперы/буфера** — резинотканевые цилиндрические отбойники по углам и
   вдоль бортов (снова аналогия с погрузчиком), носовой бампер-дуга.
7. **Детализация утилитарности**: жёсткие топливопроводы к RCS-группам,
   баллоныN2/топлива по бортам рамы, технологические панели с винтами,
   предупредительные полосы (жёлто-чёрные) на буферах, пара рабочих огней
   (2 фары + 2 позиционных стробоскопа), сцепной/швартовочный захват спереди.

## Этапы моделирования (в Blender, bpy-скриптами)
1. **Блок-аут**: кубы-примитивы — рама, контейнер-заглушка 2×2×4 для проверки
   габарита, кабина, рейлинг. Проверка силуэта с 4 сторон.
2. **Рама и вилы**: булевы/профили, скругления 2–5 мм (bevel-модификатор).
3. **Кабина**: цилиндр → фаски, гранёное стекло отдельным объектом (Glass/emit),
   шейка крепления, обшивка с панелями.
4. **Рейлинг**: кривые-дуги + bevel-профиль, стойки массивом.
5. **RCS-группы**: один набор «сопло + скоба» как массив/linked-duplicates,
   расстановка по 6 граням. Скобы — кривая-подкова с квадратным bevel.
6. **Буфера, баки, провода, огни**: мелочь на завершающем проходе.
7. **Материалы** (game-ready PBR): 3–4 материала —
   - M_hull: оранжево-бежевая эмалевая обшивка (как стройтехника) + потёртости,
   - M_frame: тёмная сталь каркаса/скоб,
   - M_rubber: буфера/шины чёрный,
   - M_glass: стекло кабины + M_light_glow для фар.
8. **Game-ready доводка**:
   - всё в один организованный set объектов с префиксом `SC_Courier_*`,
   - scale применён, origin в центре нижней грани (точка «посадки»),
   - три-четыре LOD-а? (для начала: один mesh ~8–12k тр., затем decimated LOD1/LOD2),
   - UV: Smart UV для frame/rail, unwrap для кабины; packing без оверлея,
   - нормали проверяются (автосглаживание + angle limit 40°).
9. **Экспорт**: `export/SC_Courier.glb` (весь сбор как один GLB, + опционально FBX).

## Открытые вопросы к ТЗ (решаю по умолчанию)
- Вход в кабину: assumed — подъёмная крыша/передняя панель (как у погрузчика — «без шлюза» трактуем как отсутствие гермошлюза, но люк для пилота есть, сверху).
- Ориентация: +Y = вперёд (нос), стандарт для вьюпорных сцен.
- Цвет: «строительная» оранжево-графитовая гамма станции.
