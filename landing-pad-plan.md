# План: вынос стыковки в модуль посадочной площадки

## Референсы (X4 / Elite Dangerous)

- **X4**: запрос разрешения → выделение **посадочной площадки** (модуля станции)
  → ручная/авто-посадка: корабль центрируется над площадкой, выравнивается по её
  осям, снижается до точки зависания; бортовой компьютер «доводит» корабль
  пружиной. Площадка — физический модуль: **любой объект с площадкой принимает
  посадку**.
- **Elite Dangerous**: площадка = размеченная площадь (где угодно, не только на
  станции); заход с малой скоростью, касание площадки → замки фиксируют корабль
  (clamps); звуковое/световое предупреждение при заходе.

Решение для проекта строится на той же логике: площадка — самостоятельная
сцена-модуль; над ней детектор (Area3D); вход корабля в детектор даёт флаг
«посадка»; точка зависания + пружина + замок (уже есть в `Docking.cs`).

## Механика посадки (доработка)

1. Над каждой площадкой — детектор (Area3D). Корабль вошёл → флаг `посадка`
   (`InLandingZone`), вышел → снят. Счётчик, чтобы перекрывающиеся зоны не
   снимали флаг раньше времени.
2. Запрос стыковки (F→`RequestDocking`) гейтится как раньше: зона от точки
   площадки + лимит скорости; повторный запрос → Capturing → пружина →
   Latched → Docked (замок, как clamps в ED).
